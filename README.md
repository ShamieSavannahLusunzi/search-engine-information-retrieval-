# Search Engine - Information Retrieval 

This was an academic assignment for my CS 3308 Information Retrieval course. I built a command-line search engine that processes queries and ranks documents by relevance.

**Technologies:** Python, Porter Stemmer, tf-idf, Cosine Similarity

**Key Features:**
- Inverted index with stopword removal and token filtering
- tf-idf weighting for measuring term importance
- Cosine similarity for ranking documents
- Returns top 20 results sorted by relevance

**Why is the Inverted Index file included?**
This search engine builds directly on top of an inverted index in a previous assignment for the same course. I have included the original 'InvertedIndex.py' file so you can see the foundational code that the search engine relies on and how the project evolved.
